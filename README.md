The excuse a robot vacuum gives after eating a sock — in the vacuum's
own deadpan voice, claiming the floor as its legal jurisdiction.

The line:

> It was on the floor. Everything on the floor is legally mine.

No apology, no malfunction story: the vacuum simply asserts property
law. The sock was on the floor, the floor belongs to the vacuum, and
therefore the sock was already its property. The joke is the vacuum
treating a household accident as a settled legal matter.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only) writes the line to `entry.txt` in the
output directory, with no trailing newline so the file is exactly one
line. It validates the gate itself: 1–200 characters, a single line,
not only white space, no leading or trailing whitespace.
